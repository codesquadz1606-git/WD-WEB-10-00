What is Javascript?
Js is both programming & scripting language.

In 1995 it was used to only design the UI & browser.

But nowdays , JS is used in multiple format:
i . Building backend (Node)
ii . Building mobile applications (React Native)
iii . Building Desktop Apps. (Electron)
iv . OOPS also supports.

Js is high level interpreted language.

JS are of three types:
i. Inline JS : It means writing JS in a HTML tag
ii. Internal JS : Adding JS within the HTML file
iii. External JS : Creating an external file for the JS & linking it.
