What is Media Tag?
It means I have to display any type of multimedia on our webpage.

Note : Always store your asset near your html file.

3 types:
i. img tag 
    a. src : It means where file is placed
    b. alt : If file is not visible , it will display.
ii. audio tag
    a. src 
    b. controls : Mandatory to use.
iii. video tag
    a. src
    b. controls : Mandatory to use.

What is break tags?
br tag : For breaking up the line.
hr tag : Draw the horizontal line.
